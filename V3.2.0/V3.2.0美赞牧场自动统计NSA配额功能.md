## 一、背景与目标

美赞牧场（如「25年招新活动」）通过扫码返量方式向门店发放商品出库额度。为保障活动可控，需要为活动配置**门店级 NUA 出库配额**，支持按活动新建、编辑、查看，并按门店维度设定单店配额。

本期需求在既有「限额配置」原型基础上做两处调整：
1. 模块命名由「限额配置」统一改为 **「NUA配额」**，与业务口径对齐。
2. NUA配额模块内**隐藏门店 NSA 出库配额相关字段**（新增 / 编辑 / 查看 / 导出均不再出现 NSA 数据），仅保留 NUA 维度配额。

> 返利配置模块的 NSA 字段隐藏（`.nsa-hide`）已纳入本文档，详见 3.3 节与第五章节「字段变更对照」。

### 3.4 NSA 配额规则：出库商品仅取规格类型为「小罐」的商品

适用范围：**NSA 配额规则的新增、编辑、查看页**。

变更内容：
1. 新增 / 编辑页点击「获取出库商品」时，系统仅返回并展示规格类型为「小罐」的出库商品；规格类型为「大罐」的商品自动过滤，不进入列表。
2. 编辑页回填数据时，若已有大罐规格商品，按上述规则过滤，仅展示小罐规格商品。
3. 查看页「出库商品」列表仅展示规格类型为「小罐」的商品，不展示大罐规格商品。

> 实现：HTML 原型中「获取出库商品」按钮调用 `getNsaGoods()`，获取时直接过滤大罐规格、仅返回小罐商品（非前端隐藏）；默认示例数据与 `restoreNsaData()` 均仅含小罐规格商品。

### 3.5 NSA配额报表：下载模板新增分销商品字段 + 批量导入支持新增

适用范围：**NSA配额报表编辑页**（列表 → 操作「编辑」）。

变更内容：

1. **下载模板**：CSV 模板由 3 列扩为 5 列 —— 门店ID / 门店名称 / **分销商品ID** / **分销商品名称** / 调整数量。
2. **批量导入**：匹配键由「门店ID + 门店名称」改为「**门店ID + 分销商品ID**」，走新增覆盖逻辑：
   - 列表中该门店 + 该分销商品**没有数据也支持导入**，生成一条新的门店-商品配额记录；
   - 已有数据时**覆盖更新**：原调整数量被导入的最新数量覆盖；
   - 导入后**实时更新合计数量与剩余数量**；
   - 任一门店的分销商品**剩余数量 < 0 时整批不允许导入**，并提示具体门店名称和商品名称；
   - 导入文件列数不足 5 列时直接拒绝并提示行号。
3. **新增行的字段初始化规则**：门店类型 = 总店；分销商品数量 / 积分商品数量 / 已用数量 = 0；合计数量 = 调整数量；剩余数量 = 合计数量；创建时间 / 更新时间 = 导入时间。

> 实现：HTML 原型中「下载模板」按钮调用 `downloadNsaReportTemplate()`（带 BOM 的 5 列 CSV，含当前表格示例行）；「批量导入」通过隐藏 file input 触发 `importNsaReport()`：逐行解析 CSV → 校验（列数 / 剩余数量 = 分销商品数量 + 积分商品数量 + 调整数量 − 已用数量）→ 任一行不通过则**整批不导入**并提示第一处错误（含门店名称 + 商品名称 + 剩余数量）→ 全部通过后按「门店ID + 分销商品ID」执行覆盖更新或新增，并实时重算合计与剩余。

**约束与统计口径**

- 同一时间段内的规则不允许重复（页面提示 ⚠）。
- **出库商品规格限制**：NSA 配额规则仅支持配置规格类型为「小罐」的出库商品，大罐规格商品不允许被获取、展示或统计。
- **分销订单**：小罐规格指定出库商品；以订单完成时间为准；仅总店可下单，统计给总店。
- **积分订单**：需获取罐码且罐码对应配置商品；以积分兑换订单已发货为准；总店/分店兑换均统计给分店关联总店。

**查看页**

顶部标题 +「启用」标签；基础信息含规则名称 / 活动ID / 活动名称 / 活动状态 / 统计时间 / 出库时间；下方出库商品列表仅展示规格类型为「小罐」的商品（只读）。
